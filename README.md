
# No Screen

> I’m trying to do a **“No Screen” challenge on the Steam Frame**.

The idea is simple:

 > If I was a Godot developer who wanted to work on the Steam Frame without using a screen at all, would it be possible?

 That’s the challenge behind this repository.

 The goal is to explore how far we can go while developing for the Steam Frame without relying on its screen. Feel free to experiment, contribute, suggest ideas, or help me figure out what’s possible.

 And if you’re around Belgium and want to experiment with me for this challenge, feel free to ping me!

---

 ### Exception: Steam Deck

 The Steam Deck is the one exception to the “no screen” rule.

 I’ll use it to record what I’m doing with OBS, since having a screen feed is important when recording the experiment.

 There’s also another useful feature: through Remote Play, the Steam Frame can use the **mouse and keyboard connected to the Steam Deck**.

 So the Steam Deck can act as the interface for the experiment while the Steam Frame remains screen-free.
